# Guide: showcase
- Prefer a sanitized public copy with synthetic data over making the working repo public.
- Or share privately: move the repo to a free GitHub organization and grant Read access.
- Before publishing: `gitleaks` over full history; if anything is found, publish a fresh repo and rotate keys.
- Use GitHub's no-reply commit email.
- README: architecture diagram, run locally in 5 minutes with seed data, link to ADRs and the agentic workflow.
- The platform rules live outside the repo: note the blueprint version in the README, or publish `_platform` too.
