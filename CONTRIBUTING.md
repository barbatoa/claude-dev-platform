# Contributing

This repository holds the engineering guidelines I work to. It is public so that anyone
working on one of my projects can read the conventions those projects follow — and so the
`prototype-v1` reference in each project resolves to something openable.

**The guidelines themselves are not open to contribution.** I am solely responsible for
them; a shared architecture only works while one person decides what it says. Pull requests
changing `_platform/` will be closed.

**Contributions to the projects are welcome.** Each project lives in its own repository
with its own issues and its own contribution rules. If you are working on one of them, read
`_platform/principles.md` and the relevant tier blueprint first — that is what this
repository is here for.

If you think a guideline is wrong, open an issue and make the argument. Changing my mind is
the intended path; changing the file is not.
